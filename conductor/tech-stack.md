# Tech Stack: gh-domino

## Overview
The `gh-domino` project is primarily built using the Go programming language, leveraging its capabilities to create an efficient and performant command-line interface (CLI) tool. As a GitHub CLI extension, it integrates directly with the `gh` command-line utility to extend its functionality.

## Programming Languages
- **Go:** The core logic and application are developed using Go, chosen for its strong concurrency features, performance, and suitability for building reliable command-line applications.

## Frameworks and Libraries
- **GitHub CLI Extension:** The project is structured as an extension for the GitHub CLI, utilizing its framework for seamless integration with GitHub's ecosystem and user experience.

## Data Storage
- No persistent data storage or database drivers are used directly by the application, as its operations are primarily focused on interacting with Git and the GitHub API.
